Pick your team

Quant Scout splits the work between two teams. Plain Python handles anything that has to be exact. Claude, run headless with claude -p, handles the part that needs judgment. Neither team trusts the other blindly.

Team Code

Python · pandas · yfinance
  • Downloads prices and computes 10 stats per stock: Sharpe, Sortino, volatility, max drawdown, VaR, beta, momentum, and trend.
  • Removes stocks that are too risky for your level before Claude sees them.
  • Fact-checks every number Claude cites and sends it back to try again if anything is off.
  • Runs a model-free ranking as a control, plus a 12-month backtest.

Team Claude

claude -p · no tools · JSON only
  • Reads the stats table for the stocks that passed the risk rules.
  • Weighs the trade-offs and ranks the top picks for your risk level.
  • Writes a short case for each pick, citing at least 2 stats, plus its main risk.
  • Lists the stocks it would avoid, with reasons.
⚠️
Server rule: Claude never does arithmetic, never sets risk limits, and has no tools: it can't browse, read files, or fetch prices. If something goes wrong, you can always tell which team made the mistake.

Obby stages

Every run clears these five stages in order.

  1. 1

    Load the data Team Code

    Daily prices for the watchlist plus SPY as the benchmark, cut off at the chosen date so there's no peeking at the future.

  2. 2

    Risk gate Team Code

    Low risk only lets through stocks with at most median volatility and no drawdown worse than -25%.

  3. 3

    The judge Team Claude

    Ranks the survivors, explains each pick with cited stats, and names what could go wrong.

  4. 4

    Fact check Team Code

    Checks the JSON shape, the ranks and the tickers, and confirms that every cited number matches the real data. If anything fails, the errors go back to Claude for up to 3 tries.

  5. 5

    Victory screen Team Code

    Writes a report with the picks, the avoided stocks, the run time and cost, and how much Claude agreed with the plain-code ranking.

How to play

Runs on your computer with Python and the Claude Code CLI. No paid API key is needed.

Grab the code

git clone https://github.com/Jcelestra03/quant-scout.git
cd quant-scout

Install the gear

python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

On macOS or Linux, use .venv/bin/pip.

Log in to Claude Code

claude auth login

If claude isn't on your PATH, set CLAUDE_BIN to the full path of the executable.

Press play

python scout.py                      # low-risk top 3
python scout.py --risk medium --top 5
python scout.py --as-of 2026-03-02   # replay a past date
python backtest.py                   # leaderboard replay

Reports are saved in reports/. Edit watchlist.txt to change the stocks.

Not financial advice. Quant Scout is a class project that ranks stocks by past statistics. Past performance doesn't predict future returns, and nothing here is a recommendation to buy or sell anything.
